# Palette's Journal - Critical Learnings

## 2025-10-09 - POS Interface Accessibility Boost
**Learning:** Icon-only buttons (such as sidebar toggle, cart clear, draft list, close buttons, and quantity adjustment controls) lacking `aria-label` or explicit text content hamper accessibility for screen reader users on POS screens.
**Action:** Always include clear, localized `aria-label` attributes on icon-only interactive elements in HTML templates.
