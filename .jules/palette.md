## 2025-08-11 - Dynamic PIN Gate Accessibility and Key Focus Delight
**Learning:** Icon-only or non-numeric PIN Gate keys require explicit `aria-label` screen-reader attributes, and keyboard navigation is greatly improved when `focus` and `blur` events dynamically mimic hover effects to provide immersive user feedback on custom keypad interfaces.
**Action:** When designing overlay screens or keypad gates, ensure all action/non-numeric keys are screen-reader labeled, and hook standard focus transitions to keep the keyboard experience consistent with mouse hover feedback.
