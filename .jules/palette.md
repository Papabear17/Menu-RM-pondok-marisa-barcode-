# Palette Journal

## 2026-11-09 - POS Grid Empty State with One-Click Reset
**Learning:** In fast-paced Point of Sale (POS) environments, cashiers frequently type quickly or switch between categories. When zero products match, displaying a blank screen creates confusion on whether data is loading or missing. Providing an empty state with a 1-click "Reset Filter & Pencarian" button prevents workflow disruption and saves the cashier from manually backspacing search queries and re-clicking "Semua".
**Action:** Always pair searchable or filterable catalog grids with an explanatory empty state and an immediate reset/clear action.
