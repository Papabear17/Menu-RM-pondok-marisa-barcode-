## 2025-08-09 - Focus Visible & ARIA Accessibility in Custom POS Overlays
**Learning:** In custom web-based POS systems, full-screen interactive modal overlays (like PIN Gates) and icon-only dashboard buttons are highly prone to keyboard accessibility issues and screen reader isolation. Specifically, using hardcoded `outline: none;` without dynamic `:focus-visible` styling completely breaks keyboard/tab navigability. Icon-only controls without `aria-label` leave screen readers with empty announcements for critical actions like toggling sidebar menus, opening/closing modals, and checking out.
**Action:** Always pair mouse hover/active events with matching `focus` and `blur` events to dynamically render clear visual focus styles (e.g. scale, border colors, shadows, outline offset). For all icon-only buttons, ensure a descriptive `aria-label` attribute is explicitly provided to guarantee semantic clarity across assistive technologies.
